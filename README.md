# Axolotl_Brain_Research 🌸🧠

> **Axo-Neuro Logistics:** An interactive multi-scale 3D research platform studying *Ambystoma mexicanum* (leucistic axolotl) brain and DNA regeneration to extract resilient logistics for Data Structures & Algorithms.

---

## 🌟 Overview

Axolotls possess the extraordinary biological capability to regenerate entire sections of their forebrain (*telencephalon*) after traumatic mechanical or chemical disruption without developing fibrotic astrocytic glial scars. 

This project explores the bio-computational bridge: **How can ependymoglial radial scaffolding, non-fibrotic extracellular matrix clearance, and blastema epigenetic switches inform next-generation fault-tolerant data structures and distributed algorithms?**

---

## ✨ Features

- **3D Anatomical Axolotl Specimen:** Real-time WebGL/Three.js simulation with procedural semi-translucent leucistic skin, micro-capillary branching, costal grooves, dense feathery coral-crimson external gills, and jointed salamander limbs.
- **Semantic Multi-Scale Zoom Engine:**
  - **Macro (1x):** Whole organism swimming homeostasis.
  - **Cranium (10x):** External gill vascularization and cranial structure.
  - **Meso (100x):** Telencephalon hemispheres and ventricular zone.
  - **Micro (1,000x):** Ependymoglial radial glia fibers and migrating neuroblasts.
  - **Nano (100,000x):** 32-Gigabase axolotl megagenome and regenerative loci (*Amx-Sox2*, *Kazald1*, *Prod1*).
- **Simulate Disruption:** Live lesion induction triggering radial glia bridging, neurogenesis, and scarless homeostatic recovery.
- **Bio-Logistics Translator & Interactive Graph Sandbox:**
  - **RadGlia-BST:** Self-healing binary search tree with localized $O(\log N)$ topological re-threading.
  - **Amx-Mesh:** Morphogen gradient-guided dynamic fault-tolerant graph routing.
  - **Blastema Persistent Buffer:** Lossless versioned memory buffer with epigenetic rollback.
- **Bio-Synthesizer:** Web Audio API sound synthesis for bio-rhythmic pulses and regenerative chimes.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn / pnpm

### Installation

```bash
git clone https://github.com/YeshwanthReddy1306/Axolotl_Brain_Research.git
cd Axolotl_Brain_Research
npm install
```

### Running Locally

```bash
npm run dev
```

Open `http://localhost:5173` in your browser.

### Building for Production

```bash
npm run build
```

## 🔬 Scientific Foundations

- **Organism:** *Ambystoma mexicanum* (Mexican Axolotl)
- **Genome:** 32-Gigabase Megagenome (~10x human genome size)
- **Neural Plasticity:** Complete absence of non-permissive chondroitin sulfate proteoglycan (CSPG) glial scars; ependymoglial radial cells retain neurogenic potential throughout adulthood.
